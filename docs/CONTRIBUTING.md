# Contributing to UU Cover Page Generator

We love your input! We want to make contributing to UU Cover Page Generator as easy and transparent as possible.

## Development Process

1. Fork the repo
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Commit your changes
6. Push to your fork
7. Create a Pull Request

## Pull Request Process

1. Update the README.md with details of changes if applicable
2. Follow the existing code style
3. Write meaningful commit messages
4. The PR will be merged once you have the sign-off of at least one maintainer

## Code Style

- Use 2 spaces for indentation
- Keep code clean and readable
- Comment your code when necessary
- Follow existing naming conventions

## Report Bugs

Report bugs using GitHub's [issue tracker](https://github.com/yourusername/CoverPageGenerator/issues)
