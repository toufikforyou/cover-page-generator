# UU Cover Page Generator

A web-based tool to generate cover pages for UU (Uttara University) projects.

## Features

- Simple and intuitive user interface
- Responsive design
- Customizable cover page elements

## Setup

1. Clone this repository

```bash
git clone https://github.com/yourusername/CoverPageGenerator.git
```

2. Open `index.html` in your web browser
